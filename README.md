# UA Legion bot — Aion 2 таймери босів

Етап 1: **Abyss-боси** за розкладом (повністю автоматично, без команд).
Етап 2 (заготовка): **польові боси** Verteron/Altgard — категорія `field` у `src/bosses.js`.

## Що робить бот
- За 10 хв до спавну пише в канал: «Спавн через …» + список босів (час показується у часовому поясі кожного).
- У момент спавну пише «Зараз з'являються!».
- Тримає одне закріплене повідомлення-«дошку» з найближчим спавном кожного боса і сам його редагує.
- Усе по категоріях: кожна категорія має свій канал і свою роль для пінгу.

## Варіант БЕЗ хостингу (GitHub Actions) — рекомендований
Нічого не працює постійно: GitHub раз на 6 годин запускає `src/run-once.js`, і він:
1. оновлює закріплену «дошку» в каналі через вебхук (мітки `<t:…:R>` самі відлічують час у Discord);
2. створює **події Discord** на найближчі 48 год (Nahma, Executors). Discord сам нагадує тим, хто натиснув «Цікаво».

Налаштування:
1. Новий репозиторій на GitHub, залий туди цю папку.
2. Канал -> Налаштування -> Інтеграції -> Вебхуки -> Новий вебхук -> Копіювати URL.
3. Repo -> Settings -> Secrets and variables -> Actions:
   - Secret `DISCORD_WEBHOOK_URL` = URL вебхука
   - (для подій) Secret `DISCORD_TOKEN` = токен бота з правом **Manage Events**, Variable `GUILD_ID` = ID вашого Discord-сервера
   - Variable `SERVER_TZ` = `Europe/Warsaw` (типово)
4. Actions -> Boss board -> Run workflow. У логу буде `Створено дошку. Додай секрет BOARD_MESSAGE_ID=…`: додай цей секрет, і дошка надалі редагуватиметься, а не дублюватиметься.

Обмеження: розклад GitHub може запізнюватись на 5–30 хв, тож дошка оновлюється приблизно кожні 6 год (для таймерів це не критично), а точних пінгів «через 10 хв» роль не дає. Для цього є події Discord. У публічних репозиторіях GitHub вимикає розклад після 60 днів без комітів.
Перевірити без відправки: `DRY_RUN=1 SERVER_TZ=Europe/Warsaw node src/run-once.js`.

## Запуск (постійно ввімкнений бот, потрібен хостинг)
1. Discord Developer Portal -> New Application -> Bot -> Reset Token (скопіюй токен).
2. Invite: OAuth2 -> URL Generator -> scope `bot`, права: View Channels, Send Messages, Embed Links, Manage Messages (для закріплення), Read Message History.
3. Режим розробника в Discord -> ПКМ по каналу -> Копіювати ID.
4. `cp .env.example .env` і заповни `DISCORD_TOKEN`, `ABYSS_CHANNEL_ID` (+ за бажанням `ABYSS_ROLE_ID`).
5. `npm install && node --env-file=.env src/index.js`

Боту потрібен доступ до каналу (якщо він приватний, додай роль бота в дозволи, як з carl-bot).
Бот має працювати постійно (VPS / Raspberry / ПК, що не вимикається).

## Серверна година
У `.env.example` стоїть `SERVER_TZ=Europe/Warsaw`: розклад вважається польським часом (EU-сервери на берлінському поясі, він однаковий з варшавським).
Сайти розходяться (одні кажуть, що всі Global на GMT+9). Перевір на першому спавні Watcher Kaira (кожні 3 год з 01:00): якщо в грі інший час, постав `Asia/Seoul`.
Скидання на всіх Global серверах однакове: 07:00 UTC.
